# 💀⚡ EVIL SKELETON SITE 💀⚡

This is my portfolio site. I originally decided to create this for an English assignment. I essentially remade a previous mock of a portfolio site for another class. I remade it from the ground up using Nuxt (We ❤️ Nuxt & Vue). This site features a new layout and currently has `4` pages.
- HOME (WiP) The first page is the home page, it explains a little about me and about the site.
- PROJECTS (Also WiP) This page shows the projects I'm proud of and/or those that I feel I learned a lot from.
- SKILLS (WiP \#3) This page lists my skills and experiences throughout my growing career. It was basically just created so I would meet requirements on the English assignment.
- ABOUT (WiP-tastic) This page is about the site and myself. The information on the site includes the stack, my experiences making it, and some things I learned and design decisions I made during development. The stuff on me is a lot more boring. It's about me.
